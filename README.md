# Controle de Gastos

Projeto de Orientação a Objetos em Python: um controle financeiro com cadastro de usuários, categorias, receitas, despesas e resumo do saldo.

## Arquivos

- `main.py`: interface gráfica (Nível 4)
- `menu.py`: menu no terminal (Níveis 2 e 3)
- `testes.py`: testes das classes (Nível 1)
- `models/`: classes do sistema e banco de dados SQLite

## Como rodar

Instale a biblioteca da interface:

pip install ttkbootstrap

Depois rode:

python main.py
